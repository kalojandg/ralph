# rwclab: разузнаване за board 3 — .NET бекенд към локален AWS

_Събрано 2026-11-14 (три read-only Explore прохода: бекенд, лабораторна сървърна страна, мрежова повърхност на фронтенда). Нищо не е билдвано или пускано. Това е ВХОДЪТ за авторството на board 3: „.NET ъпгрейд както идва + закачане бекенд↔фронтенд + локален AWS". Решение на потребителя: бекендът `app/backend` се ПАЗИ и пренасочва; не се заменя с Node, не се трие. Нищо не бива да стига до AWS акаунта на SprintRay (731672801406, us-west-2)._

Пътищата по-долу са спрямо `app/backend/`, освен ако не е казано друго.

## 0. Десетте неща, които определят формата на board 3

1. **AWSSDK е 3.3.x** (Core ≈ 3.3.10x; няма `obj/project.assets.json`, няма пакети в `~/.nuget`). `AWS_ENDPOINT_URL` НЕ се поддържа (иска Core 3.7.300+). Тоест: или ъпгрейд на SDK до 3.7.x (върви с .NET ъпгрейда), или endpoint през `AWS:ServiceURL` в конфигурацията.
2. **Една точка на инжекция за всички AWS клиенти, само в Development:** `Web/Startup.cs:137-140` `services.AddDefaultAWSOptions(Configuration.GetAWSOptions())`; всички `AddAWSService<>` са в `Web/Infrastructure/Extensions/ServiceCollectionExtenstions.cs:63-81`. Трябва локален stub (най-просто: малък endpoint в самия бекенд или статичен JSON, към който сочи `ResinOnCloud:Url`).

Върви при всеки `PlatformJobUpdated`/`StatusUpdated` event. Емулаторът НЯМА AppSync data plane → заменя се с локален push (SNS→SQS→WebSocket в бекенда или отделен gateway).
7. **Pipeline-ът НЕ стартира state machine директно за платформата:** праща SQS съобщение `{pipelineArn, parameters}` в `RaywareCloudPlatformProcess` (.fifo), а външна wrapper Lambda стартира машината. Само preprocess (`RayWareCloudPreProcesing`) и edit (`RayWareCloudEditPlatformProcessing`) са директни `StartExecution`.
8. **`database update` на чист Postgres ще падне:** миграция `DataLayer/Migrations/20220216100534_SwitchPatientFromDoctorToOffice.cs:71-89` прави `DROP VIEW public."CloudTabPage"`, `"DoctorsPage"`, `"PatientsPage"`, `"TimeToDesignPage"` без `IF EXISTS`, а view-тата се създават само от `DataLayer/Scripts/Views/*.txt`. Плюс: 8× `OWNER TO sprintray` (роля `sprintray` трябва да съществува, напр. `20210126191911…:46`), `CREATE PROCEDURE` (PG ≥ 11), нула seed за lookup таблиците.

10. **CORS:** `DomainSettings:AllowedOrigins = "http://localhost:4202"` (`Web/appsettings.json:92`, split на `Startup.cs:181`) → добави `http://localhost:45280`. Няма HTTPS redirect, няма HSTS. Health: `GET api/health`, анонимен.
